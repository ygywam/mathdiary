# 📐 수학 수업 성찰 일기 (Math Reflection Journal)

> **"배움과 성장을 기록하는 매일 5분 수학 성찰 피드백 웹앱"**

교사의 학기 고정 수업코드 개설, 2022 개정 수학 교육과정 1클릭 단원 자동완성, 학생 개인별 성찰 일기 작성 및 RLS 기록 격리, 교사용 3단 다차원 필터링 대시보드, 그리고 A4 가로 2쪽(A5×2) 규격 인쇄를 제공하는 교육용 플랫폼입니다.

---

## 🌟 주요 기능

1. **학생 개인별 안심 일기장**
   - 실명/연락처 수집 없이 '학번 + 4자리 PIN'으로 간편 로그인
   - 타인의 글은 일체 열람할 수 없는 본인 전용 성장 타임라인 보관함
   - 자연스러운 한국어 4문항 발문 (AI 부연설명 및 영어 병기 배제)
2. **교사용 수업 관리 & 3단 다차원 대시보드**
   - 학기/학급 고정 수업코드(예: `MTH-203`) 발급
   - 2022 개정 수학 교육과정(공통수학1, 대수, 미적분 등) 1클릭 단원 완성
   - 날짜별 / 학생별(생기부 과세특 작성용) / 단원별 다차원 필터링
3. **A4 가로 2쪽(A5×2) 규격 인쇄 지원**
   - A4 가로 1장에 A5 규격 2매가 나란히 자동 분할 배치
   - 답변 완료본(포트폴리오용) 및 줄노트 빈칸(오프라인 학습지용) 모드 지원

## 🚀 빠른 시작

### 1) 무설치 브라우저 직접 실행
`공유용/index.html` 파일을 더블클릭하면 설치 없이 즉시 모든 기능을 체험할 수 있습니다.

### 2) 개발 환경 실행 (Next.js)
```bash
npm install
npm run dev
```
브라우저에서 `http://localhost:3000` 접속
